Furniture workspace — published snapshot

Open https://anakondr.github.io/furniture-viewer/

This repository contains the interactive viewer and generated design assets.
The Python CAD source and development history are maintained separately.
No server is required: controls, geometry switching and previews run in the browser.
Downloads are the original generated STEP, STL, DXF and cutting-list files.
Comparison findings describe differences in the DXF reconstruction, including
edge drilling that is not represented in the DXF machining layers.

The publication date and design fingerprint appear at the bottom of the viewer.
Changing this snapshot does not change the editable Python design.
Three.js is vendored under its MIT licence in vendor/THREE-LICENSE.txt.
